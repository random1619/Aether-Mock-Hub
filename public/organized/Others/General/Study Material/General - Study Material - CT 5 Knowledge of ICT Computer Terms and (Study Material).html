Q1

What is the Recycle bin?
रीसायकल बिन क्या है?
A software for deleting files
A default folder for temp files
A default folder for downloads
A temporary storage for deleted files
फ़ाइलों को डिलिट करने के लिए एक सॉफ्टवेयर
अस्थायी फ़ाइलों के लिए एक डिफ़ॉल्ट फ़ोल्डर

Solution:

The correct answer is option 4. i.e. A temporary storage for deleted files.

  • When you delete a file or folder in Windows, it is placed in the Recycle Bin. Items are temporarily stored in the Recycle Bin before they are permanently deleted by the user.
  • The Recycle Bin is located on the Windows desktop.
  • You can open the Recycle Bin by double-clicking the icon on the Windows desktop.
  • The Recycle Bin window allows you to delete items individually or restore them to their original location.
  • If you want to permanently remove all items in the Recycle Bin, select "Empty the Recycle Bin" in the left sidebar of the window.
  • A small icon of a waste container for deleting files was implemented during the development of the Apple Lisa user interface in 1982, where it was called the "Wastebasket".

सही उत्तर विकल्प 4 अर्थात् डिलीट की गई फ़ाइलों के लिए एक अस्थायी स्टोरेज है।

  • जब आप विंडोज में कोई फाइल या फोल्डर डिलीट करते हैं, तो उसे रीसायकल बिन में रखा जाता है। उपयोगकर्ता द्वारा स्थायी रूप से हटाए जाने से पहले आइटम को रीसायकल बिन में अस्थायी रूप से संग्रहीत किया जाता है।
  • रीसायकल बिन विंडोज डेस्कटॉप पर स्थित होती है।
  • आप विंडोज डेस्कटॉप पर आइकन पर डबल-क्लिक करके रीसायकल बिन को खोल सकते हैं।
  • रीसायकल बिन विंडो आपको व्यक्तिगत रूप से आइटम को हटाने या उन्हें उनके मूल स्थान पर पुनर्स्थापित करने की अनुमति देता है।
  • यदि आप रीसायकल बिन में सभी आइटम स्थायी रूप से हटाना चाहते हैं, तो विंडो के बाएं साइडबार में "इम्पटी द रीसायकल बिन" चुनिये।

Solution:

There are different components in the computer system. they all have their own working mechanisms. some component takes input, some process the data and some give output. all these components combine and make our work easier, comfortable, and convenient.

 Input device
  • An input device is any hardware device that sends data to a computer, allowing you to interact with and control it.
  • For example, Mouse, Keyboard, Touchpad, Scanner, Digital Camera, Microphone, Joystick, Graphic Tablet, etc.

Output device

 
  • An output device is any piece of computer hardware equipment that converts information into a human-readable form. It can be text, graphics, tactile, audio, and video.
  • For example, Monitor, Printer, Audio Speakers, Headphones, Projector, GPS, Sound Card, Video Card, Braille Reader, Plotter

 
Software
  • Software is a set of instructions, data, or programs used to operate computers and execute specific tasks.
  • For example, MS-office, Office suites, Database programs, Web browsers, Word-processors, Software development tools, Image editors, Communication platforms.
Web browser
  • A web browser, or simply "browser," is an application used to access, view websites, and the internet.  
  • A browser lets you do activities like login, view multimedia, link from one site to another, visit one page from another, print, send and receive the email, etc.
  • For example, Chrom, Microsoft Internet Explorer, Google Chrome, Mozilla Firefox, Apple Safari

For instance, a keyboard or computer mouse is an input device for a computer, while monitors and printers are output devices. Devices for communication between computers, such as modems and network cards, typically perform both input and output operations.

The communication line between the CPU, memory and peripherals is called a ______.

Line

None of these
बस 
लाइन

Solution:

The correct answer is Bus.

Key Points

  • A bus is a connection between components or devices connected to a computer.
  • A bus carries data between a CPU and the system memory via the motherboard.
  • The bus contains multiple wires (signal lines) with addressing information describing the memory location of where the data is being sent or retrieved.
  • For example, a computer with a 32-bit address bus can address 4 GB of memory.
  • A bus is either a parallel or serial bus, and either an internal bus (local bus) or an external bus (expansion bus).

Additional Information

Term Use
Line In communications, a line refers to a cable or wire that connects two devices to each other.
Media Media is a term used to describe computer storage.

Q4

 A computer virus is a:
कंप्यूटर वायरस होता है:
Software that saves the computer from being damaged
Application software that helps to make different type of viruses and worms
Program that spreads itself and destroys other programs

एप्लीकेशन सॉफ्टवेयर जो विभिन्न प्रकार के वायरस और वर्म्स में अंतर में मदद करता है।

प्रोग्राम जो आपके कंप्यूटर में समस्याओं को ठीक करता है। 
Solution:

The Correct Answer is "Program that spreads itself and destroys other programs".

Important Points

  • A computer virus is designed to spread from host to host and has the ability to replicate itself.
  • A computer virus is a type of malicious code or program written to alter the way a computer operates and is designed to spread from one computer to another.
  • A virus operates by inserting or attaching itself to a legitimate program or document that supports macros in order to execute its code.
  • In the process, a virus has the potential to cause unexpected or damaging effects, such as harming the system software by corrupting or destroying data.

Additional Information

  • A computer virus attack can produce a variety of symptoms. Here are some of them:
    • Frequent pop-up windows: Pop-ups might encourage you to visit unusual sites. Or they might prod you to download antivirus or other software programs.
    • Changes to your homepage: Your usual homepage may change to another website, for instance. Plus, you may be unable to reset it.
    • Mass emails being sent from your email account: A criminal may take control of your account or send emails in your name from another infected computer.

Key Points

  • Use a trusted antivirus product, such as Norton AntiVirus Basic, and keep it updated with the latest virus definitions.
  • Avoid clicking on any pop-up advertisements.
  • Always scan your email attachments before opening them.
  • Always scan the files that you download using file-sharing programs.

  • कंप्यूटर वायरस, दुर्भावना से बनाया गया एक ऐसा कोड या प्रोग्राम होता है जिसे किसी कंप्यूटर को संचालित करने के तरीके को बदलने और एक कंप्यूटर से दूसरे कंप्यूटर में फैलाने के लिए डिज़ाइन किया जाता है।
  • वायरस अपने कोड को निष्पादित करने के लिए मैक्रो का समर्थन करने वाले वैध प्रोग्राम या दस्तावेज़ में खुद को सम्मिलित या संलग्न करके संचालित होता है।

    • आपके होमपेज में परिवर्तन: उदाहरण के लिए आपका सामान्य होमपेज दूसरी वेबसाइट में बदल सकता है। साथ ही, आप इसे रीसेट करने में असमर्थ हो सकते हैं।
    • आपके ईमेल खाते से सामूहिक ईमेल भेजना: कोई अपराधी आपके खाते को कंट्रोल कर सकता है या किसी अन्य संक्रमित कंप्यूटर से आपके नाम पर ईमेल भेज सकता है।
