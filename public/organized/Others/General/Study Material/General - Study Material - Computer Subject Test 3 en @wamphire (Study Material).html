The correct answer is Image file.

Solution:

The correct answer is 128.

Which among the following is NOT an operating system ?

Solution:

The correct answer is Router.

  • The Router is not an operating system.

Key Points

  • An operating system is software that performs all the basic tasks like file management, memory management, process management, handling input and output, and controlling peripheral devices such as disk drives and printers.
  • A router is a physical or virtual appliance that passes information between two or more packet-switched computer networks.
  • A router inspects a given data packet's destination Internet Protocol address (IP address), calculates the best way for it to reach its destination, and then forwards it accordingly.
  • It is a common type of gateway. It is positioned where two or more networks meet at each point of presence on the internet. 
  • Android, iOS, and Windows are examples of the operating system.

  • राउटर एक ऑपरेटिंग सिस्टम नहीं है।

Q7

World Wide Web (WWW) is a collection _______on the internet forms.
वर्ल्ड वाइड वेब (WWW) इंटरनेट रूपों पर _________ का एक संग्रह है।
Hyperlinked document
E-mail
Mailing list
Hypertext markup language

ई-मेल
मेलिंग लिस्ट 
हाइपरटेक्सट मार्कअप लैंग्वेज
Solution:

The correct answer is a Hyperlinked document.

Key Points

World Wide Web

  • The World Wide Web is commonly known as the Web.
  • It is an information system where documents and other web resources are identified by Uniform Resource Locators.
  • These documents are interlinked by hypertext and are accessible over the Internet.
  • The resources of the Web are transferred via the Hypertext Transfer Protocol (HTTP).
  • These resources are also accessed by users of a software application called a web browser.
  • And these resources are published by a software application called a web server.

Hyperlinked document

  • A hyperlink is a reference to data that the user can follow by clicking or tapping.
  • A hyperlink points to a whole document.
  • A hyperlink can also point to a specific element within a document.
  • Hypertext is text with hyperlinks.
  • The text that is linked is called anchor text.
  • A software system that is used for viewing and creating hypertext is a hypertext system, and to create a hyperlink is to hyperlink.
  • A user following hyperlinks is said to navigate or browse the hypertext.

Additional Information

Types of Hyperlink Documents

Text hyperlink Uses a word or phrase to take visitors to another page, file, or document.
Image hyperlink   Uses an image to take visitors to another page, file, or document.
Bookmark hyperlink Uses text or an image to take visitors to another part of a web page.

सही उत्तर हाइपरलिंक्ड डॉक्यूमेंट है 

Key Points

वर्ल्ड वाइड वेब

  • वर्ल्ड वाइड वेब को आमतौर पर वेब के रूप में जाना जाता है।
  • यह एक सूचना तंत्र है जहां डॉक्यूमेंट और अन्य वेब संसाधनों की पहचान यूनिफ़ॉर्म रिसोर्स लोकेटर द्वारा की जाती है।
  • ये डॉक्यूमेंट हाइपरटेक्स्ट द्वारा इंटरलिंक किए गए हैं और इंटरनेट पर उपलब्ध हैं।
  • वेब के संसाधनों को हाइपरटेक्स्ट ट्रांसफर प्रोटोकॉल (HTTP) के माध्यम से स्थानांतरित किया जाता है।
  • ये संसाधन वेब ब्राउज़र नामक एक सॉफ़्टवेयर एप्लिकेशन के यूज़र्स द्वारा भी एक्सेस किए जाते हैं।
  • और ये संसाधन वेब सर्वर नामक एक सॉफ्टवेयर एप्लिकेशन द्वारा प्रकाशित किए जाते हैं।

  • हाइपरलिंक पूरे डॉक्यूमेंट को इंगित करता है।
  • हाइपरलिंक किसी डॉक्यूमेंट के भीतर एक विशिष्ट तत्व को भी इंगित कर सकता है।

  • जो टेक्स्ट लिंक्ड है, उसे एंकर टेक्स्ट कहा जाता है।
  • हाइपरटेक्स्ट को देखने और बनाने के लिए उपयोग किया जाने वाला एक सॉफ़्टवेयर सिस्टम एक हाइपरटेक्स्ट सिस्टम है, और हाइपरलिंक बनाने के लिए हाइपरलिंक है।
  • हाइपरलिंक का अनुसरण करने वाले उपयोगकर्ता को हाइपरटेक्स्ट को नेविगेट या ब्राउज़ करने के लिए कहा जाता है।

Q8

What is the full form of TCP/IP, with reference to internet protocols? 
इंटरनेट प्रोटोकॉल के संदर्भ में TCP/IP का पूर्ण रूप क्या है?
Transfer Control Protocol and Internet Protocol
Transmission Control Protocol and Internet Protocol
Transmission Control Protocol and International Protocol 
None of the above
ट्रांसफर कंट्रोल प्रोटोकॉल और इंटरनेट प्रोटोकॉल

Solution:

The correct answer is Transmission Control Protocol and Internet Protocol.

Key Points

  • TCP/IP stands for Transmission Control Protocol and Internet Protocol.
  • The Internet protocol suite is the conceptual model and set of communications protocols used in the Internet and similar computer networks.
  • It is commonly known as TCP/IP because the foundational protocols in the suite are the Transmission Control Protocol (TCP) and the Internet Protocol (IP). 

Additional Information

  • Hypertext Transfer Protocol (HTTP) is an application-layer protocol for transmitting hypermedia documents, such as HTML.
  • SMTP stands for Simple Mail Transfer Protocol. 
  • The File Transfer Protocol (FTP) is a standard communication protocol used for the transfer of computer files from a server to a client on a computer network.

  • The Autosum Excel function can be accessed by typing ALT +  = sign in a spreadsheet, and it will automatically create a formula to sum all the numbers in a continuous range. It allows you to easily add up a series of numbers either vertically or horizontally without having to use the mouse or even the arrow keys on the keyboard.
  • The Autosum Excel shortcut is very simple – just type two keys: ALT =
    • Step 1: Place the cursor below the column of numbers you want to sum (or to the left of the row of numbers you want to sum).
    • Step 2: hold down the Alt key and then press the equals = sign while still holding Alt.
    • Step 3: press Enter.

Additional Information

  • The symbol ">=" indicates the 'Greater than or equal to' in MS Excel.
  • The symbol "<=" indicates the 'Less than or equal to' in MS Excel.
  • The symbol "<>" indicates 'Not equal to' in MS Excel.
