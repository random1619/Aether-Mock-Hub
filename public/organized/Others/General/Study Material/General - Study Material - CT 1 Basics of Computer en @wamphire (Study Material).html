On which of the following concept the fifth-generation computers are based?

Solution:

Correct answer Both 1 and 4

Key Points:

  • The fifth-generation computers are based on Ultra Large Scale Integration (ULSI) and their working is primarily focused on Artificial Intelligence.
  • The operating system used in the fifth generation is based on Knowledge Information Processing System.
  • The fourth-generation (present) computers in beginning used Large scale integration (LSI) and currently using Very Large Scale Integration(VLSI). 
  • Super Large Scale Integration (SLSI) is emerging technology.
  • The second generation of computers used Transistors which were based on semiconductors.
  • The third-generation computers were based on integrated circuits made up of silicon.
  • the first-generation computers were based on vacuum tubes.

सही उत्तर 1 और 4 दोनों है।

  • पाँचवीं पीढ़ी के कंप्यूटर अल्ट्रा लार्ज स्केल इंटीग्रेशन (ULSI) पर आधारित हैं और इनका काम मुख्य रूप से आर्टिफिशियल इंटेलिजेंस पर केंद्रित है।
  • पाँचवीं पीढ़ी में प्रयुक्त ऑपरेटिंग सिस्टम नॉलेज इंफॉर्मेशन प्रोसेसिंग सिस्टम पर आधारित है।
  • शुरुआत में चौथी पीढ़ी (वर्तमान) के कंप्यूटरों ने बहुमात्रा एकीकरण (LSI) और वर्तमान में अति बृहद स्तरीय एकीकरण (VLSI) का उपयोग किया। सुपर लार्ज स्केल इंटीग्रेशन (SLSI) उभरती तकनीक है।
  • दूसरी पीढ़ी के कंप्यूटरों ने ट्रांजिस्टर का उपयोग किया जो अर्धचालकों पर आधारित थे।
  • तीसरी पीढ़ी के कंप्यूटर सिलिकॉन से बने इंटीग्रेटेड सर्किट पर आधारित थे।
  • पहली पीढ़ी के कंप्यूटर वैक्यूम ट्यूब पर आधारित थे।

Q3

A Computer system, which contains two or more CPU is called a _______.
एक कंप्यूटर सिस्टम, जिसमें दो या दो से अधिक CPU होते हैं, उसे _______ कहा जाता है।
Input data
Control Unit
Multiprocessor Unit
Global memory
इनपुट डेटा
कंट्रोल यूनिट
मल्टीप्रोसेसर यूनिट
ग्लोबल मेमोरी
Solution:

The correct option is (3)

Multiprocessor Unit

Concept:-

The employment of two or more central processing units (CPUs) within a single computer system is known as multiprocessing.

Key Points

  • An electronic device with two CPUs. In contrast to dual core systems, which have two processors integrated into a single CPU chip, dual processor systems (DP systems) contain two distinct CPU chips.
  • An integrated circuit with two or more processing cores attached for improved performance and lower power consumption is called a multicore processor. Additionally, these processors allow for the more effective parallel processing and multithreading of numerous tasks.
  • The ALU and Control Unit are the two components of the CPU. The Arithmetic Logic Unit (ALU) conducts both logical and arithmetic operations, including addition and subtraction (such as comparing two values). The Control Unit interprets and executes commands.

Additional InformationControl Unit:- A computer's CPU contains hardware called a control unit, or CU, which controls operations. It specifies how the computer's memory, logic board, and input and output devices should react to the program's instructions.

Input data:- Input refers to any data that is given to a computer or software application. The act of entering information into a computer is sometimes referred to as data entry because the information delivered is also regarded as data.

Global memory:- The primary memory area, known as global memory, is where data from the host and GPU are shared.

सही विकल्प (3) है।

मल्टीप्रोसेसर यूनिट

अवधारणा:-

एक ही कंप्यूटर सिस्टम के भीतर दो या दो से अधिक सेंट्रल प्रोसेसिंग यूनिट (CPUs) के नियोजन को मल्टीप्रोसेसिंग के रूप में जाना जाता है।

Key Points 

  • दो CPU वाला एक इलेक्ट्रॉनिक उपकरण। दोहरे कोर सिस्टम के विपरीत, जिसमें दो प्रोसेसर एक CPU चिप में एकीकृत होते हैं, दोहरे प्रोसेसर सिस्टम (DP सिस्टम) में दो अलग-अलग DP चिप्स होते हैं।
  • बेहतर प्रदर्शन और कम बिजली की खपत के लिए दो या दो से अधिक प्रोसेसिंग कोर के साथ एक एकीकृत सर्किट को मल्टीकोर प्रोसेसर कहा जाता है। इसके अतिरिक्त, ये प्रोसेसर अधिक प्रभावी समांतर प्रसंस्करण और कई कार्यों के मल्टीथ्रेडिंग की अनुमति देते हैं।
  • ALU और कंट्रोल यूनिट CPU के दो घटक हैं। अरिथमेटिक लॉजिक यूनिट (ALU) जोड़ और घटाव (जैसे दो मानों की तुलना करना) सहित तार्किक और अंकगणितीय संचालन दोनों का संचालन करता है। कंट्रोल यूनिट कमांड की व्याख्या और निष्पादन करती है।

Additional Information कंट्रोल यूनिट:- कंप्यूटर के CPU में हार्डवेयर होता है जिसे कंट्रोल यूनिट या CU कहा जाता है, जो संचालन को नियंत्रित करता है। यह निर्दिष्ट करता है कि कंप्यूटर की मेमोरी, लॉजिक बोर्ड और इनपुट और आउटपुट डिवाइस को प्रोग्राम के निर्देशों पर कैसे प्रतिक्रिया देनी चाहिए।

इनपुट डेटा:- इनपुट किसी भी डेटा को संदर्भित करता है जो कंप्यूटर या सॉफ़्टवेयर एप्लिकेशन को दिया जाता है। कंप्यूटर में सूचना दर्ज करने का कार्य कभी-कभी डेटा प्रविष्टि के रूप में जाना जाता है क्योंकि दी गई जानकारी को डेटा भी माना जाता है।

ग्लोबल मेमोरी:- प्राइमरी मेमोरी एरिया, जिसे ग्लोबल मेमोरी कहा जाता है, वह है जहां होस्ट और GPU से डेटा साझा किया जाता है।

Which of the following is an input device and an output devices at the same time?

इनमें से कौन-सा एक ही समय में एक इनपुट डिवाइस और एक आउटपुट डिवाइस है?

Solution:

The correct answer is Modem


Key Points

  • Modem:
    • A modem is considered an input/output device because a modem sends and receives data at the same time.
    • The word "modem" stands for "modulator-demodulator"
    • For example, whenever you are surfing, you send a web page request that its info out, or output. When you receive or access web pages, which would entail an input device. During receiving, error handling, and correction - again data is transmitted to the concerned server. Hence, it is called an I/O device.

Additional Information 

  • Printer:
    • A printer is a hardware output device that is used to generate hard copies and print any document.
    • A document can be of any type such as a text file, image, or a combination of both. It accepts input commands by users on a computer or on other devices to print documents.
  • Keyboard:
    • A keyboard is one of the primary input devices that allows users to input text into a computer or any other electronic machinery.
    • It is a peripheral device that is the most basic way for the user to communicate with a computer. It consists of multiple buttons, which create numbers, symbols, letters, and special keys like the Windows and Alt keys, including performing other functions.
  • Joystick:
    • A joystick is an input device that can be used for controlling the movement of the cursor or a pointer in a computer device.
    • The pointer/cursor movement is controlled by maneuvering a lever on the joystick. 
    • The input device is mostly used for gaming applications and, sometimes, in graphics applications.

सही उत्तर मॉडम है।

Key Points 

  • मॉडम :
    • मॉडम को एक इनपुट/आउटपुट डिवाइस माना जाता है क्योंकि एक मॉडम एक ही समय में डेटा भेजता और प्राप्त करता है।
    • "मॉडेम" शब्द "मॉड्यूलेटर-डिमोडुलेटर" के लिए है।
    • उदाहरण के लिए, जब भी आप सर्फिंग कर रहे होते हैं, तो आप एक वेब पेज अनुरोध भेजते हैं ताकि इसकी जानकारी या आउटपुट प्राप्त किया जा सके।
    • जब आप वेब पेज प्राप्त करते हैं या उन तक पहुंचते हैं, तो इसके लिए एक इनपुट डिवाइस की आवश्यकता होगी। प्राप्त करने के दौरान, त्रुटि प्रबंधन, और सुधार - फिर से डेटा संबंधित सर्वर को प्रेषित किया जाता है। इसलिए, इसे I/O डिवाइस कहा जाता है।

  • कीबोर्ड:
    • एक कीबोर्ड प्राथमिक इनपुट डिवाइस में से एक है जो उपयोगकर्ताओं को कंप्यूटर या किसी अन्य इलेक्ट्रॉनिक मशीनरी में टेक्स्ट इनपुट करने की अनुमति देता है।
    • यह एक उपकरण है जो उपयोगकर्ता के लिए कंप्यूटर के साथ संचार करने का सबसे बुनियादी तरीका है। इसमें कई बटन होते हैं, जो संख्याएँ, प्रतीक, अक्षर और विशेष कुंजियाँ जैसे विंडोज और Alt कुंजियाँ बनाते हैं, जिसमें अन्य कार्य करना भी शामिल है।
  • जॉयस्टिक:
    • जॉयस्टिक एक इनपुट डिवाइस है जिसका उपयोग कंप्यूटर डिवाइस में कर्सर या पॉइंटर की गति को नियंत्रित करने के लिए किया जा सकता है ।
    • जॉयस्टिक पर लीवर को घुमाकर पॉइंटर/कर्सर की गति को नियंत्रित किया जाता है।
    • इनपुट डिवाइस का उपयोग ज्यादातर गेमिंग अनुप्रयोगों के लिए और कभी-कभी ग्राफिक्स अनुप्रयोगों में किया जाता है।

Solution:

The correct answer is A circuit board that connects all the external and internal hardware.

Key Points

  • A circuit board that connects all the external and internal hardware is the function of the Motherboard on the computer ​
    • It is also called a system board.
    • It is the main printed circuit board (PCB) in general-purpose computers.
    • It holds and allows communication between many crucial electronic components of a system, such as the central processing unit (CPU) and memory, and provides connectors for other peripherals.
    • It also has expansion slots to add more peripheral devices to the computer.

Additional Information

  • The first motherboard is considered to be one used in the IBM Personal Computer, released in 1981.
  • At the time, IBM called it a "planar" instead of a motherboard.

  • Computers of this generation used machine language as their programming language.
  • ENIAC, EDVAC, UNIVAC, IBM-701 and IBM-650 are the computers used in this first generation of computing.

Additional Information

  • Second-generation computer: In the second-generation computer, the technology used is a transistor. The material used behind the transistor is made of a semiconductor.
  • Third-generation computer: In the third-generation computer, the technology used is an IC or Integrated Circuit. In this generation, high-level language is used.
  • Fourth-generation computer: In the fourth-generation computer, the technology used is VLSI and microprocessor.
